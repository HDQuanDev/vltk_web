# Audit streaming trước Work Package A

Đọc source v0.4 ngày 19/10/2026. Yêu cầu gốc: [FULL_OFFLINE_RPG](../FULL_OFFLINE_RPG.md); yêu cầu tiếp nối: [CONTINUATION_FROM_v0.4](../CONTINUATION_FROM_v0.4.md). Không thay thế hoặc giảm scope.

| Hệ thống         | Source trước sửa                                                                                | Khoảng trống / quyết định                                                                                                                                             |
| ---------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Navigation       | WeakMap Set blocked cells, binary heap A*, maxVisited16384                                      | Không có chunk graph; sửa blocked cùng chiều dài có thể giữ cache cũ. Thêm chunk16/component/gateway, LRU64, mutation API/invalidation; cùng ngân sách cho toàn query |
| Simulation       | AI của mọi monster trên map có player, scan toàn entities tìm target/pack                       | Thêm spatial buckets16, active24/nearby48/inactive, nearby AI1Hz, preserve combat/DOT/cast/return. Không freeze status damage hoặc reset HP/phase khi streaming       |
| Spawn            | Tất cả static placements được tạo khi vào map                                                   | Giữ stable IDs của map cũ. Map mới dùng weighted circle/polygon zones, min/max/density/caps/levels/elite/respawn/activation/safe validation, 4 spawn mỗi tick         |
| Loot             | Global512, từ chối toàn bộ drop sau cap                                                         | Pool64/region +512 active +2048 serialized reserve, rare ưu tiên thay common, expiry và counters; từ chối cuối cùng thông báo rõ                                      |
| Terrain          | Tạo tất cả missing chunks cùng một update                                                       | Ưu tiên viewport, prefetch, tối đa2/frame và dừng sau4ms khi đã tạo ít nhất1; hủy queue camera cũ, ownership destroy/remove texture                                   |
| Actor/loot views | Tạo toàn map hoặc giữ view ẩn sau khi đi xa                                                     | Hủy view ngoài viewport; giữ authority data. VFX pool hiện có được giữ                                                                                                |
| Local session    | Clone cả snapshot20Hz                                                                           | Thêm tick/clone diagnostics. Chưa Worker/delta publish hoặc persistent region paging; phải đo lại trước40maps                                                         |
| Map content      | 4maps, map lớn128, 6monsterdefs/1boss/11items/15quests/5NPC                                     | Thêm một map256 có hoạt động; không nhân bản definitions để tăng số lượng                                                                                             |
| Persistence      | Create giới hạn5 nhưng import gọi save không kiểm tra slot; list dừng cả roster nếu 1record lỗi | Áp giới hạn/unique name trong transaction save/import, per-slot recovery UI, preserve source/backup/archive                                                           |
| Assets           | 5PNG review, procedural actor/NPC/VFX/audio                                                     | Tiếp tục yêu cầu production art, không chứng nhận từ renderer/validator                                                                                               |

Phạm vi A được đo ở map thật256; không tuyên bố đã xác minh512/1024, hàng nghìn NPC, GPU memory hoặc hiệu suất điện thoại thật. Async navigation/Worker và paging giữ trong backlog nếu cold-index/device measurements yêu cầu.
